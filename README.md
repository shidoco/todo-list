# Todo List
A simple, responsive task managemnet application designed to help users organize a todo list.

## Screenshots

## Features

- **Todo Actions:** Create, edit, delete, and mark todos as completed.
- **Filter + Search:** Filter todos by status (All, Active or Completed) and search by keywords.
- **Responsive Layout:** Design adapts to all screen sizes.
- **Persistence:** List persists across sessions. 

## Technology Used

- **Frontend:** React, HTML5, Tailwind CSS
- **State Management:** React Context API / Reach Hooks
- **Build Tool:** Vite

## Installation / Getting Started

Follow these instructions to get a local copy running on your machine. 

First, make sure you have **Node.js** and **npm** installed on your computer.

1. Clone the repository:

    ```bash
    git clone <repository-url>
    cd todo-list
    ```
2. Install the dependencies:

   ```bash
   npm install
   ```

### Available Scripts
To run the development server, run the following in your terminal:

   ```bash
   npm run dev
   ```
Then open the app in your browser at the URL shown in the terminal: http://localhost:5173.

This builds the production-ready app to the dist folder:

   ```bash
   npm run build
   ```
To locally preview the production build, run the following in your terminal:

   ```bash
   npm run preview
   ```
Running the following runs ESLint to check for code formatting/quality issues:

   ```bash
   npm run lint
   ``` 

## Design Decisions

**Minimalist UX:** Prioritized a clean card based layout.
**Design System**: Used Tailwind CSS to build a consistent design system (typography, color pallettes, spacing).
